# 03. 실측 맵 적용 — 시뮬 건물을 실제 신공학관과 일치시키기

> 상태: ⏸ 실측 대기 · 담당: Lee · 선행: 01 (02와 병렬 가능) · 갱신: 2026-07-03
> 메모: 현재 테스트 복도는 의도적 5m 확장(CORRIDOR_HALF=2.5, 회귀 가드로 고정).
> 신공학관 실측(약 2.0m) 후 improvement_report §1.8 절차대로 재생성·재튜닝한다.

## 목표

레퍼런스 기반 가상 맵을 실측 치수로 교체한다. 복도 폭/문 위치가 실제와 다르면 동적 장애물 회피와 엘베 정밀 주행 튜닝이 전부 실기에서 무효가 된다.

## 작업 단계

### 1단계: 현장 실측

- [ ] 측정 항목: 복도 폭/길이, 엘베 홀 치수, 엘베 문 폭과 칸 내부 가로·세로, 방 문 폭과 간격, 택배존 위치/치수, 문턱·경사
- [ ] 도구: 레이저 거리계 권장, 사진 + 간단 스케치 동반
- [ ] 측정값을 `src/common_pkg/config/kku_pre_simulation_map.yaml`에 반영할 수 있는 형태로 표 정리 (개인정보가 들어간 사진은 repo/Notion에 올리지 않음)

### 2단계: world 재생성 파이프라인 재사용

- [ ] `kku_pre_simulation_map.yaml` 갱신 (기존 스키마 유지: 벽 세그먼트, 문 폭, 복도 중심선)
- [ ] `python3 scripts/generate_kku_worlds.py`로 `kku_f{1,2,3}.world` 재생성
- [ ] 층별 SLAM 재맵핑 → `save_kku_map.sh`로 맵 저장 → `kku_nav_points.yaml`의 routing 중심선(`main_corridor_x/y`) 갱신

### 3단계: 좌표 재캡처와 회귀

- [ ] 01 단계의 캡처 절차 반복 (맵이 바뀌면 모든 포인트 무효)
- [ ] 회귀 9종 + L5 재실행

### 4단계 (선택, 로봇 반입 가능 시): 실건물 SLAM 맵

- [ ] 실제 건물에서 teleop SLAM으로 맵을 뜨고 시뮬 맵과 겹쳐 오차 확인
- [ ] 오차가 큰 구간(유리벽, 반사면)을 기록 — 실기 AMCL 튜닝 자료

## 완료 기준

- 실측 기반 F1/F2/F3 맵으로 L5 재통과.
- 실측값 표가 `hardware_spec.md` 또는 맵 YAML 주석에 기록됨.

## 리스크 / 안전·보안 체크

| 리스크 | 대응 |
|--------|------|
| 유리벽/반사면이 LiDAR에 안 잡힘 | 실측 단계에서 위치 기록, world에 별도 재질 반영 또는 실기 시 가상 벽(keepout) 후보로 |
| 실건물과 시뮬 맵 원점 불일치 | 엘베 문 중앙 기준 원점 규약을 YAML 주석으로 고정 |
| 건물 측정 중 통행 방해 | 측정은 비혼잡 시간대, 2인 1조 |
