# 04. 동적 장애물/사람 회피 시뮬레이션

> 상태: [70%] 🔄 · 담당: Lee · 선행: 02 · 갱신: 2026-07-03
> 실제 진행: 사람형 보행자 다중 배치(`/gazebo/set_entity_state` 폐루프, F2 뒤 복도 포함),
> RPP 충돌 예측 감속(use_collision_detection) + 곡률/비용 감속으로 통과 검증(WITH_PEDESTRIAN=1).
> 남은 것: nav2_collision_monitor 정지/감속 존 도입, S1~S5 시나리오 3회 무충돌 정식 매트릭스.

## 목표

복도에 사람과 장애물이 있는 상태에서 충돌 없이 미션을 완주하고, 피할 수 없으면 안전하게 멈추는 동작을 시뮬에서 확정한다.

## 작업 단계

### 1단계: 시뮬 환경 구축

- [ ] Gazebo actor로 보행자 2~3명 추가 (world 또는 별도 spawn): 복도 횡단, 마주 걷기, 추월 경로 스크립트
- [ ] 정적 장애물 세트(박스/의자 모델)를 복도 무작위 위치에 배치하는 스크립트 작성
- [ ] 장애물 배치는 시나리오 파일(YAML)로 재현 가능하게

### 2단계: Nav2 회피 튜닝

- [ ] local costmap obstacle layer가 `/scan`을 반영하는지 확인, `obstacle_max_range`/`raytrace_max_range` 점검
- [ ] inflation/controller critic 튜닝: 사람과 최소 이격 거리 목표 0.5m
- [ ] recovery behaviors(spin, backup, wait) 동작 확인 — 막힌 복도에서 무한 회전하지 않는지
- [ ] `nav2_collision_monitor` 도입: 전방 정지 존(stop zone) + 감속 존(slowdown zone) 설정

### 3단계: 시나리오 매트릭스 검증

| 번호 | 시나리오 | 통과 기준 |
|------|----------|----------|
| S1 | 정지 장애물 1개, 복도 중앙 | 우회 통과, 충돌 0 |
| S2 | 마주 오는 보행자 1명 | 감속+우회 또는 정지 후 재개, 충돌 0 |
| S3 | 복도 횡단 보행자 (갑자기 등장) | collision monitor 정지, 통과 후 재개 |
| S4 | 복도 완전 차단 | 안전 정지 + 재시도, 무한 헤매기 없음 |
| S5 | 엘베 문 앞 대기 인파 | 문 앞 정지 대기, 공간 생기면 진입 |

- [ ] 각 시나리오 3회 반복, 결과 기록

### 4단계: 회귀

- [ ] 장애물 없는 기본 L5가 튜닝 후에도 통과하는지 (회피 튜닝이 일반 주행을 망치지 않았는지)

## 완료 기준

- 시나리오 S1~S5 각 3회 충돌 0.
- 기본 L5 회귀 통과.

## 리스크 / 안전·보안 체크

| 리스크 | 대응 |
|--------|------|
| A1m8은 2D 스캔 — 발/낮은 장애물 미탐지 | 한계로 문서화, LiDAR 장착 높이 결정에 반영(02), 실기에서는 저속 운행으로 보상 |
