# Journal 2026-06-01

작성일: 2026-06-02

## 요약

2026-06-01에는 기존 엘리베이터 mission PoC에서 Nav2 주행이 코너를 대각선으로 뭉개며 이동하는 문제를 줄이기 위해 waypoint 기반 직각 라우터를 추가했다.

## 진행 내용

- `test_workspace/elevator_mission/scripts/orthogonal_router.py`가 층별 복도 중심선을 기준으로 route waypoint를 생성하도록 구성되었다.
- F2/F3 방 이동은 `main_corridor_x=2.0`을 기준으로 복도 중심선을 따라 이동한 뒤 방 앞에서 접근한다.
- F1 택배존 이동은 `main_corridor_y=0.0`을 기준으로 복도축을 따라 이동한 뒤 진입한다.
- `delivery_mission_node`는 단일 `NavigateToPose` 대신 `NavigateRoute`로 경유점을 순차 전송한다.
- Nav2 코너 통과가 자연스럽도록 `src/slam_pkg/config/nav2_params.yaml`의 goal tolerance도 조정되었다.

## 확인된 의미

층 이동을 포함한 mission 흐름에서 같은 층 주행은 더 예측 가능한 구조가 되었다. 특히 방 앞 접근 pose와 복도 중심 이동을 분리하면서, 다음 단계인 엘리베이터 도착 후 맵 전환을 붙일 기반이 생겼다.

## 남은 문제

- 기존 `test_workspace/elevator_mission/`은 여전히 수동 2-Phase floor switch 구조다.
- 엘리베이터가 목표층에 도착해도 Nav2 map server가 자동으로 목표층 map을 load하지 않는다.
- `/floor_orchestrator/ack`를 사람이 호출해야 mission이 이어진다.
