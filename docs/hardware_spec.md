# Hardware Spec (SSOT)

> 하드웨어 사양의 단일 기준 문서. 변경은 반드시 이 파일에서만 하고, 다른 문서는 여기를 링크한다.
> 상태: 초기 작성 2026-07-03 (AGENTS.md 요약 + 세션 기록에서 취합). 실측/확정값은 Han/Kim 검토 후 갱신할 것.

## 1. 확정 사양

### 1.1 제어 스택

| 항목 | 사양 | 비고 |
|------|------|------|
| 주 컴퓨터 | NVIDIA Jetson Xavier NX | aarch64, 6코어 — ROS2는 컨테이너로 구동 |
| MCU 1 | OpenCR 1.0 | IMU 9축 + 바퀴 모터 제어 |
| MCU 2 | Arduino Nano | 모터 제어 보조 |
| OS/미들웨어 | JetPack + Docker + ROS2 Humble | JetPack은 Ubuntu 20.04라 Humble 직접 설치 불가 |

### 1.2 센서

| 항목 | 사양 | 비고 |
|------|------|------|
| LiDAR | RPLiDAR A1m8 | 360°, 실내 유효 8m 설정 (`slam_toolbox_params.yaml` max_laser_range) |
| IMU | 9축 (OpenCR 내장) | odom 보정용 |
| 카메라 | 웹캠 2개 | 로봇팔 visual servoing + 주행 보조 |

### 1.3 구동/기구 (시뮬 반영값)

| 항목 | 사양 | 비고 |
|------|------|------|
| 주행 방식 | 2륜 차동 + 볼롤러 | 하중 목표 20kg |
| 바퀴 간격 | 0.51324 m | Fusion 실측 — `delivery_robot.urdf.xacro` 반영 |
| 바퀴 지름 | 0.066 m | 동일 |
| 섀시 | 0.3 x 0.4 x 0.25 m | 동일 |
| Z축 리프트 | 웜기어 + T스크류, 행정 0.5m(URDF) / 설계 0.7m | 적재 5kg |
| 로봇팔 | 4 DOF, 리치 60cm, 서보 | Kim — 엘리베이터 버튼 조작 |
| LiDAR 장착 높이 | z = 0.750 m | URDF 기준 |

### 1.4 시뮬-실기 차이 (URDF `★SIM` 보정)

- 접지 클리어런스 0.02m 추가 (실물 설계에는 없음 — HW팀 전달됨)
- 전방 캐스터 추가 (전복 방지 — 실물 COM_x +11mm 지지 다각형 밖 이슈 HW팀 전달됨)
