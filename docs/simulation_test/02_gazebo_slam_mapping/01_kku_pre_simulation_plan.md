# KKU Pre-Simulation Map Plan

## 목적

건국대학교 신공학관 도면을 확보하기 전까지, LiDAR 실측을 기다리지 않고 SLAM Toolbox, Gazebo, RViz2, 이후 Nav2 테스트를 진행하기 위한 가상 건물 맵을 만든다. 이 문서는 사용자가 해야 할 결정과 Codex에게 시킬 구현 작업을 분리해 정리한다.

## 반영된 구조

기준 구조는 엘리베이터에서 내린 로봇의 진행 방향을 기준으로 잡는다. 엘리베이터에서 내리면 오른쪽 복도가 길게 이어지지만, 방은 그 오른쪽 복도에 두지 않는다. 방은 엘리베이터 왼쪽 코너를 돌아 들어가는 건물 뒤쪽 복도에 있고, 뒤쪽 복도의 양쪽 벽에 서로 마주보게 배치한다.

```text
2F / 3F  (※ 복도 끝은 모두 막힌 벽 — LiDAR가 무한공간으로 인식하지 않도록)

                                    [207]   [208]
                                    [205]   [206]
                                    [203]   [204]   ← 뒤쪽 복도 (+y, 끝벽 ▣)
                                    [201]   [202]
                                       |       |
                                       +-------+
                                          ↑  좌회전 코너 (엘베 바로 옆)
                                          |
                                  [ELEV]  |   
 ------------------------------------------▣  ← 오른쪽 복도, 방 없음

 엘베에서 내리자마자 바로 좌측 코너 → 좌회전하면 뒤쪽 복도
 코너에서 오른쪽으로 돌면 방 없는 긴 복도
```

1층은 같은 엘리베이터 위치를 기준으로, 오른쪽으로 돌면 있는 복도 쪽에 택배 집하 공간을 둔다. 택배존은 **복도 남쪽으로 튀어나온 alcove(쪽방) 형태**로, 복도와 0.9m 문으로 연결된다. 좌측 코너 뒤쪽 복도 구조도 형태는 유지하지만 1층에는 방을 배치하지 않는다(층간 SLAM 맵 형태 일관성 목적). 단, F1 뒤쪽 복도는 F2/F3보다 짧게 둬도 된다.

```text
1F

                                 |
                                 |   뒤쪽 복도 (+y, 방 없음, 끝벽 ▣)
                                 |
                                 +
                                 ↑ 좌회전 코너 (엘베 바로 옆)
                                 |
                        [ELEV]   |
 ─────────────────────────|------|   ← 오른쪽 복도 (끝벽 ▣)
        │ door 0.9m │
        ┌───────────┐
        │  PARCEL   │   ← alcove 형태로 복도 남쪽에 부착
        │   ZONE    │
        └───────────┘
```

## 추천 사양

- 층수: 3층
- 1층 역할: 택배 수령, 엘리베이터 탑승, 층 이동 시작
- 2층/3층 역할: 배송 목적지
- 호수: 배송층마다 8개, 총 16개
- 배치: 오른쪽 복도에는 방 없음, 좌측 코너 뒤쪽 복도 양쪽 벽에 4쌍
- 복도 폭: 2.0m
- 복도 길이: F1 오른쪽 15m / 뒤쪽 8m, F2·F3 오른쪽 22m / 뒤쪽 14m (YAML 기준)
- 복도 끝벽: 모든 복도 끝은 막힌 벽으로 처리 (dead-end)
- 방 크기: 폭 2.5m × 깊이 3.0m (시뮬레이션 단순화용 표준값)
- 엘리베이터 내부: 1.6m x 1.6m
- 엘리베이터 문 폭: 1.0m
- 택배존: 1F 오른쪽 복도 남쪽에 alcove 형태로 부착, 0.9m 문으로 진입
- 가상 LiDAR 기준 최대거리: 8.0m
- SLAM 맵 해상도: 0.05m/cell
- 층별 frame_id: `map_f1`, `map_f2`, `map_f3` 로 분리 (논리적 층 전환 시 TF 충돌 방지)

## 생성된 맵 정보 파일

구조화된 pre-simulation 맵 스펙은 다음 파일에 저장했다.

- `src/common_pkg/config/kku_pre_simulation_map.yaml`

이 파일은 Gazebo world를 직접 생성하기 전의 기준 데이터다. 층별 복도, 엘리베이터, 방 문 위치, 접근 pose, 택배존, 추천 테스트 경로를 포함한다.

## 정합성 노트 (YAML ↔ Plan 일치 사항)

- 좌표계: origin=엘리베이터 중앙, +x=오른쪽 복도 방향, +y=뒤쪽 복도 방향
- 택배존: YAML의 `parcel_zone` center=(5.0, -1.8), size=(3.0, 1.8)은 복도 남쪽 alcove 해석을 따른다. world 생성 시 복도 남쪽 벽에 0.9m 문 개구를 두고 alcove 외곽 벽을 추가한다
- F1 뒤쪽 복도: 형태만 유지하고 방은 두지 않는다. SLAM 맵 일관성 목적
- 복도 끝벽: YAML `right_corridor.x_end`, `back_corridor.y_end` 좌표에 두께 0.12m 벽 세그먼트를 자동 생성한다
- 호수 명명: `201~208`, `301~308` 유지

## 구현 방향

초기 구현은 실제 3D 엘리베이터를 물리적으로 위아래로 움직이지 않고, 논리적 층 전환 방식으로 만든다.

1. 로봇이 현재 층 엘리베이터 안으로 진입한다.
2. 엘리베이터 문 닫힘 상태를 시뮬레이션한다.
3. 목표 층 상태를 선택한다.
4. Gazebo world를 목표 층으로 바꾸거나, 목표 층 엘리베이터 내부 pose에 로봇을 respawn한다.
5. 엘리베이터 문 열림 상태를 시뮬레이션한다.
6. 로봇이 목표 층 복도로 나와 목적 호수로 이동한다.

이 방식은 초기 졸업작품 시연에서 충분히 설득력 있고, SLAM/Navigation/상태머신을 먼저 검증할 수 있다. 나중에 시간이 남으면 엘리베이터 문 애니메이션, 층 표시 topic, cabin 모델을 추가한다.
