# 단계별 예상 문제와 대응

작성일: 2026-10-07. 단계 ID는 [01_scenario_and_architecture.md](01_scenario_and_architecture.md), 작업 번호(Wxx)는 [03_gap_and_work_breakdown.md](03_gap_and_work_breakdown.md), 코드 지적(CR-xx)은 [02_code_review_2026-10-06.md](02_code_review_2026-10-06.md)를 따른다.

표기:

- **★** 실제 현장·로그에 같은 문제가 기록된 항목. 근거를 괄호에 적었다.
- **◆** 코드·설정·문서로 이미 확인된 결함이나 동작. 현장 발생 기록은 없다.
- 표시가 없으면 예상 문제다. 발생 여부는 ⚠️미확인이다.
- "대응"은 설계·코드로 막는 방법이다. 현장에서 실패했을 때의 기본 행동은 01 문서 2절 표를 따른다.
