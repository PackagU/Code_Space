# 버튼 인식·팔 제어 코드

Jetson의 2026-09-16 최신 독립 시험 코드를 보존했다.

| 파일 | 역할 |
|---|---|
| `vision.py` | 흰 원형 캡 검출, 숫자 템플릿 비교, ▲▼ 판정 |
| `calib.py` | 픽셀 좌표에서 보정된 PWM 계산 |
| `arm.py` | 서보 프로토콜, 조그, 누르기 사이클 |
| `app.py`, `index.html` | 카메라 입력과 등록·보정·미리보기 화면 |
| `servo_test.py`, `servo_reference.py` | 현재 서보 자세·명령 형식·누르기 시간 |
| `data/` | 숫자 등록 템플릿, 보정점, ▲▼별 자세 |
| `test_button_arm.py`, `check.py`, `synth.py` | 합성 영상·가짜 드라이버 기반 오프라인 시험 |

숫자 1은 메뉴 6, 숫자 4는 메뉴 7 자세를 사용한다. ▲▼는 저장한 별도 자세를 사용한다. 코드의 기본 실행은 팔 포트를 열지 않는 미리보기이며, 실제 팔 모드는 현장 승인과 명시적 실행 옵션을 요구한다.

과거 합성·카메라 입력 검증은 [VALIDATION.md](VALIDATION.md)에 있다. 해당 기록은 당시 환경의 시험이며 현재 수정본의 실물 버튼 접촉 성공 기록은 아니다.
