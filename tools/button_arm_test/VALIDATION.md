## 오프라인으로 확인한 동작

- `servo_test.py`는 AST로 값만 읽는다. 파일에 `arm = ServoArm(PORT, BAUD)`가 있어도 실행하지 않는다. 포즈 하나라도 다르면 거부한다.
- 보정 누르기 계획에 servo_test의 press/press2를 넣으면 기존 메뉴 6/7 명령 문자열·시간과 **바이트 단위로 같다**.
- 3점 이상 affine 보정은 선형 기준 매핑을 ±1 PWM 이내로 복원한다. 영역 밖, 캡 크기 25% 초과 변화, 2점 직선에서 벗어난 버튼은 거부한다.
- 임무 규칙(내부 올라감→4, 내려감→1, 탑승 전 ▲/▼)을 확인했고 2·3은 목표로 설정할 수 없다.
- 목표 중복, 영상 끊김, 토큰 불일치, 동작 중 명령, 다른 origin 요청은 거부한다.
- 가짜 드라이버 기준: home 응답이 불일치하면 명령 0개로 정지하고, 중간 응답이 불일치하면 PDPT 정지·포트 닫기를 하며 자동 retreat은 없다.
- 미리보기 모드에서 조그·이동은 시리얼을 열지 않는다. PWM_LIMITS 밖 조그는 거부한다.
- 브라우저(합성 영상 8092)에서 등록 3회 → 보정점 추가 → 조그 → 누르기 미리보기 흐름을 확인했다. 3점 삼각형 밖 버튼은 "보정 영역 밖"으로 거부됐다.

## 실행하지 않은 것

실제 모드(`--execute`) 실행, 팔 포트 열기, 조그·누르기는 하지 않았다. 기존 ROS 노드·컨테이너·운영 코드는 건드리지 않았다. 의존성 설치, git commit/push도 하지 않았다.
